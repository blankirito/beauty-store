# 顾客登录与订单支援指引

本指引只供 Lumina 的支援人员与管理员使用。

## 密码与登录协助

当顾客无法登录时，只询问：

- 顾客的账号电邮地址
- 简短说明登录时遇到的问题

不要询问、接收、查看、记录或设置顾客的密码。

如果顾客原本使用 Google 登录，请提醒他们使用相同电邮地址点击 Continue with Google。

如果顾客无法恢复账号，请先确认情况是否合适，再建议他们注册新账号。未经验证授权，不要在账号之间转移订单、个人资料或店铺权限。

## 订单协助

如顾客咨询订单，只询问：

- 订单编号
- 下单时使用的电邮地址

只通过受保护的 Lumina Admin Dashboard 查看订单。

在未验证对方身份前，不要透露顾客地址、电话号码、付款参考资料、订单内容或账号资料。

## 访客订单追踪

访客完成付款后会立刻获得一条私人订单追踪链接。

- 提醒访客将链接保存在安全的位置，并且不要分享给别人。
- 不要要求顾客通过 WhatsApp、电邮、截图或公开讯息发送访客追踪 token。
- 不要新增仅凭订单编号、姓名、电邮或电话号码查询订单的功能。

如果访客遗失追踪链接，不要在未验证的支援对话中透露私人订单资料。请先升级处理，并通过已认可的方式确认订单归属。

## 账号、付款或身份争议

不要只因为一则支援讯息，就手动更改账号归属、订单归属、付款状态、商家权限或平台权限。

以下情况必须升级处理：

- 付款争议
- 诈骗或可疑活动
- 遗失访客追踪链接
- 要求在不同账号之间转移资料或订单
- 要求取得 Admin、Merchant 或 Platform 权限

请保留简短的内部记录：顾客的请求、已验证的资料，以及最终采取的行动。
