# Customer Sign-in and Order Support

This guide is for Lumina support operators only.

## Password and sign-in help

When a customer cannot sign in, ask only for:

- Their account email address
- A short description of the sign-in problem

Do not ask for, receive, view, store, or set a customer's password.

If the customer originally used Google Sign-In, ask them to use Continue with Google using the same email address.

If the customer cannot recover access, ask them to register a new account only if they confirm that it is appropriate for their situation. Do not transfer orders, personal data, or store access between accounts without verified authorization.

## Order help

For an order-related question, ask only for:

- The order number
- The email address used for the order

Check the order only through the protected Lumina admin dashboard.

Do not reveal customer addresses, phone numbers, payment references, order details, or account information to a person whose identity has not been verified.

## Guest order tracking

Guest customers receive a private tracking link immediately after checkout.

- Tell guests to keep the link private and save it somewhere safe.
- Never ask customers to send their guest tracking token through WhatsApp, email, screenshots, or public messages.
- Never add an order lookup using only an order number, name, email address, or phone number.

If a guest loses their tracking link, do not disclose private order details through an unverified support conversation. Escalate the case and verify ownership through an approved process before taking any action.

## Account, payment, or identity disputes

Do not manually change account ownership, order ownership, payment status, merchant access, or store permissions based only on a support message.

Escalate cases involving:

- A disputed payment
- Fraud or suspicious activity
- A lost guest tracking link
- A request to move data or orders between accounts
- A request for admin, merchant, or platform access

Keep a short internal record of the request, what was verified, and the action taken.
